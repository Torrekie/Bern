# macOS 13 原生逻辑验收

2026-10-25，用户直接说明：不需要像素级复现；Bern 最终应生成符合目标平台逻辑的 UI，允许难以避免的细微系统版本差异。本文件是当前验收合同，优先于旧记录中的精确像素、RGB、ICC、坐标或逐帧一致门槛。

仍先完成真正的 `swiftui-modern` / `macos_modern` macOS 13 阶段。继续允许新编译器、新 SDK 与 deployment target 13 的组合；macOS 11 / Swift 5.3、Objective-C 与 iOS 阶段尚未开始。优先复用现有 Bern 结构及系统控件，仅在功能确实需要时增加适配，不为复制另一系统的细小外观差异创建控件。

## 判断标准

- 构建与运行：实际二进制来源可追溯、最低系统为 13，14+ API 有正确 availability 保护和实质替代；不能有缺符号、启动或交互崩溃。
- 原生外观与布局：采用目标系统的语义颜色、材质、控件状态和布局惯例。文字、选择、禁用状态可辨；主要内容和操作可达；调整窗口后能继续使用。
- 功能与状态：按钮、选择、文本、菜单/弹出层、媒体等实际操作按 Bern 接口更新正确模型与 UI。禁用状态生效，提交不重复，不把 IPC 成功响应当成焦点或动作结果。
- 动画与手势：有应有的可见运动、正确目标及可继续操作的终态；取消、离页和 Reduce Motion 不留下隐藏内容、残影或卡住的临时状态。允许原生弹簧、吸附阶段和短时轨迹不同。
- 基本可访问性与键盘：主要控件角色、名称、值和禁用状态合理；焦点与常用键盘操作可达，不错误截获文本编辑。按实际风险抽样验证，不要求全量控件/输入法/VoiceOver矩阵。

系统标题栏、侧栏位置、bezel、少量间距/卡高、抗锯齿、材质灰阶及几 pt 落点差异，本身不构成功能失败。原生颜色差异不需要固定 RGB 或补偿曲线来消除。仍须处理实质问题，例如内容空白/严重错误、错误目标、不可达操作、重复提交、输入被吞、动画结束仍失效或错误宣称系统能力。

旧精确对比保留为诊断资料；不会删除原始差值，也不会将原采集、清理或输入交付失败改写为通过。物理 HDR 亮度校准不由 SDR 截图证明；能力范围要如实说明。工具未投递输入应记为未验证，既不自动判产品故障，也不能借 CLI 编辑补成原生输入通过。

## 执行顺序与收束

按用户的新标准，当前macOS13阶段在已审查的兼容路径及Showcase/Gallery代表性流程范围满足验收：构建、运行、原生外观与可达布局、状态恢复、限定动画终态、媒体及常规键盘编辑/提交均有依据。复用足够的历史证据，缺失的连续响应、实际挂载及前台输入已补足，没有为消除细微系统差异修改产品。Gallery Frame明确`controls:none`；macOS13 Inspector使用系统HSplitView且源码没有动画承诺，不增加矩阵或动画。不再运行像素、Row ledger、14.5 pt或观察器零影响路线，也不为细小色差重新触发远程CI。

验收范围不包含全示例/控件变体、物理HDR校准、硬件输入、IME、VoiceOver及自动化鼠标投递保证；旧进程的短时Loading/超时最终结果未知，不能声称已定因或修复。这些限制不改写为成功，也不扩大为未证实的13移植故障。macOS11 API/Swift5.3、Objective-C和iOS仍未进入本轮；后续须沿用本机13实际结果与同一原生逻辑标准逐阶段移植。历史work别名与归档驱动不得直接执行。
