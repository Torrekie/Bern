# Actual snapshot → fixed SDR display recipe (source only)

Base is the repository `hero-cgsemantics-probe`, not CG-direct. Assemble in one file: `ProductHero.base.swift` → **unchanged** `FloatCapture.swift.inc` → `SnapshotSDR.swift.inc` → `Driver.swift.inc`; retain the existing separate ProductImage, ProductStyle and Dependencies. Driver already contains BackingObservation. Root owns the recorded SDK14 gain-map/unused-clock adaptations, build and execution.

`BERN_HERO_SNAPSHOT_SDR=default|baked-named` is process-cached; unset is default, invalid fails before window creation. Both modes require float=on, backing=off, expected/actual OS13 and the exact known opaque/up named fixture asset. Default's converter/binder/check return before new image-property reads and create no CI objects or output. The original observer/FloatCapture receives the original renderer-return image in both modes.

Only the named primary snapshot is eligible. Its already-recorded RGB3/16float/64bpp/16Little/premult-last layout, exact 320×180 or 640×360 extent and logical320×180 size must pass. CIImage receives the original CGImage with `.toneMapHDRtoSDR:true`, no input-space override/relabel/resize/orientation/filter. One ordinary CIContext renders one RGBA8/sRGB image from that exact extent, `deferred:false`; unknown layout/extent/output or conversion failure is sticky. Named NSImage is constructed from this derived image using the original logical size. A weak reference identifies this **derived display NSImage**, not an original-CG→NSImage association. The original Flight class/two draw calls, custom/body/oracle, window/stability/deadline/cache/front paths remain unchanged.

Before capture, after each saved PNG and after final native guards, candidate checks that the same named display NSImage remains both Flight endpoints, with original bounds/corner and one cached derivative/context. No original snapshot provider/NSImage readback is added. The primary-freeze hook precedes original teardown; cleanup snapshots use original pixels and do not convert/rebind. After original window teardown and unchanged FloatCapture.finish, helper finish records derived public format/color-space/ICC metadata, then clears only its derived/context/scalar/weak display references. It does not claim NSImage/system deallocation or zero observer effect.

Report `snapshot_sdr_display` contains requested/selected, success/error, primary_frozen; conversion_count/context_create_count/cache_hit_count/cleanup_passthrough_count; records[]; phase_checks[]; metadata_stage; helper_references_cleared/release_scope. The single candidate record includes key, input scalar object ID/layout/extent, logical size, requested tone-map=true/**actual application unknown**, input override=false, requested output format/space, deferred=false, start/elapsed, derived CGImage/display NSImage scalar IDs, post-teardown output metadata/ICC. Phase checks hold stage/phase/uptime and scalar identities. Default has empty records/checks and zero context/conversion counts. Cleanup passthrough count counts candidate-mode cleanup invocations only. Ordinary failures retain partial record/error and cause nonzero exit, including post-defer finalization failure.

No compile/UI/CI was performed. `validation.json` checks exact Float/base copies, unchanged Flight source, one renderer read and one CI render call; patch roundtrip is checked separately. Runtime default must first reproduce prior12ROI/raw/semantics; candidate other10ROI must remain exact and named atlas must be visibly complete/nonblank/correctly oriented (alpha255 alone is insufficient). Root owns runtime/pixel acceptance. This recipe cannot isolate the Bool from output conversion, predict improvement, or establish High/true coordinated-flight equivalence.
