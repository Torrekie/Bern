# macOS13 原生逻辑验收建议

本次按用户新口径：目标系统上逻辑正确、可用的原生UI，允许细微系统外观差异。仍只验真正swiftui-modern/macOS13；11/Swift5.3、ObjC、iOS延期。根已确认goal active；子线程goal=null是作用域差异。本文件是未执行的清单，不是阶段完成结论。

## 最小执行清单

复用已交付Showcase9dd/Gallerye48及现有证据，不重建探针、矩阵或远程CI；若修实质问题，再仅重验受影响路径。

1. 构建与来源：锁定源码/资源和实际App/CLI；完整构建、arm64、min13与签名已有证据可复用。复核14+符号受正确availability保护、13替代分支存在；新SDK/Swift6可继续使用，不要求本阶段Swift5.3。新源码的局部typecheck不能替代其完整构建。
2. 外观与布局：在现有普通设置下，一次正常窗口浏览主要页面，切一次浅/深色并缩窄、恢复窗口。确认文字/选中/禁用状态可辨、语义色和材质合理，内容/主按钮可达、不重叠或不可恢复裁切。无需统一像素、toolbar位置、bezel或卡高。
3. 操作与状态：在原页面完成按钮/Toggle、一次滑块预览→提交、文本编辑→提交/错误→重试、菜单/Popover开关及关闭、Settings开关。核真实UI与模型同步、单次动作不重复、禁用无效。CLI可补状态证据，不能代替鼠标/焦点交付；工具未送达事件记未验证，不直接判产品bug。
4. Gallery：Inspector显隐/拖divider后内容仍可达；Film初始内容可辨，First/Last确实导航且手动滚动后仍可继续；Frame播放/暂停/seek及Caption/Size可操作、关闭后恢复。复用已有成功步骤，只补未覆盖的实质行为，不要求旧坐标逐值相等。
5. 动画：代表性滚动、nudge/pinch或hero各按其现有示例检查一次启动→运动→正确终态，并在离页/取消后无残影、隐藏控件或仍运行的临时状态。容许系统弹簧/吸附轨迹和时长差异；保留Reduce Motion语义，不为测试更改用户全局设置。静态端点和逻辑progress不单独证明运动通过。
6. 轻量可访问性：上述操作顺带核主要控件的角色/名称/值/禁用状态；一次Tab/ShiftTab及常用快捷键，文本编辑和输入法不被全局键监听抢走。无需全量VoiceOver或变体矩阵；可见控件无可达焦点/动作、键盘陷阱属实质问题。

## 判断与收束

非阻断：系统材质灰阶、原生标题/toggle布局、4pt卡高、14.5pt落点、细小标签宽度或抗锯齿差，前提是不影响目标内容、操作、辨识或可达性。不能将所有色差预先归为细微：图像黑白/缺失、严重错误色彩/透明度、假HDR能力、主线程卡住仍须处理；SDR截图不证明物理HDR等效，可明确其未承诺范围。

阻断：启动/API缺失崩溃、状态写回/目标错误、重复提交、不可达或遮挡的主要操作、焦点/输入被错误截获、过渡结束仍隐藏/失效，以及产品明确承诺却无效果的动作。搜索command焦点在当前模板13/14同走无searchFocused路径，注释声明15前不支持；不自动视作13回归。可见搜索框输入/过滤仍须功能证据；不得用返回成功替代焦点实证。

旧exact PNG/RGB/ICC、整数ROI、严格frame/14.5pt、observer零影响和逐帧时序门槛均留作历史诊断，退出本阶段阻断清单。原失败/工具交付限制不改成PASS。HDR数值、物理亮度、全动画/输入法等旧未证事项按本次实际合同标明，不以标准放宽推导已完成。

结束条件：根逐项标记“既有证据满足/本次实测满足/实质缺陷待修/范围外说明”，解决实质缺陷并保留简短来源与结果后，才能验收mac13并决定下一阶段。无需复拍已足够的历史证据；本review未运行UI、测试代码、编译、CI或Git。
