# One actual coordinator replacement

This fixture compiles the exact product Hero block with imports and a separate
entry point. It uses the existing actual BernImage/BernPictures/Motion/Probe
and original clock; no metadata hook, FloatCapture, manual Flight, enter/leave/
tick/finish/visibility call, layer request or SDK14 unused-clock guard is added.

A MainActor ObservableObject Boolean changes once after a stable source image.
Normal SwiftUI branches use the same named-PQ URL and nonempty key, different
explicit identities and legal320x180 positions. Existing manager is discovered
from the attached source anchor; only weak source/flight references survive
the replacement. Read-only scalar sampling pins one real registered flight,
requires timer/frame/progress movement, then actual automatic retirement,
removed overlay view and a detached/deallocated old source.

Before/settled each need five identical own-window buffers. The first observed
real0.2<progress<0.8 produces one in-flight WindowServer PNG with before/after
state and uptime brackets, without freezing, seeking, replaying or a stability
requirement. Success retains exactly three original PNGs with ICC. Native
collection success does not establish image visibility/color or synchronized
animation equivalence; offline raw-PNG inspection remains mandatory.

The executable requires expected13/14, existing screen-capture permission,
normal accessibility flags, default motion, a nonkey/inactive owned fixed
window, unchanged front/cache and no MTKView including overlay siblings.
Preload3s, initial1.5s, collection7.2s/hardwindow7.9s,512 samples and outer15s
bound the single attempt. Failures retain partial evidence without retries.
The wrapper unsets BERN_MOTION only in its child environment, changes no
preferences/permissions and refuses prior reports/receipts.

CI builds once with SDK26.2, Swift5mode, arm64/min13 and runs on14. The same
original signed binary must run13 without rebuilding/resigning. Original
source hashes, actual package/architecture/minOS/signature and per-process
receipts precede acceptance. Local SDK14.2 target14 typecheck used the archived
ProductImage gainmap compiler adaptation only; it is not a min13 build/run,
and those image guards are absent from this newSDK package.

CLI: binary namedAsset output; BERN_HERO_EXPECT_OS=13|14. The wrapper CLI adds
expectedOS as its fourth argument. Real conditional replacement is a fixture
state action, not physical mouse/keyboard evidence. Retarget/reversal, other
images/alpha/High/HLG/geometries and full-app parity remain separate gates.
