# Private normal-AppKit-loop coordinator observer

Source only; no compilation, UI, CI, repository or product edit. Base delayed driver SHA=`b9d6b699af43128b0658ecb9e81df8ef346e6f9b3be253c07cca80968bcd8ec6`. The complete helper prefix before the old @main is byte-identical. `app-loop-driver.patch` describes the single execution-model change; assembly still uses unchanged actual ProductHero.exact plus the existing Image/Style/Dependencies and newSDK26.2/min13 same-binary13/14 contract.

`FixtureAppRun` is the MainActor state owner and application delegate. Main calls NSApplication.run exactly once; applicationDidFinishLaunching starts the original async cache load and one default-mode1/60 selector Timer. The3s preload limit is checked against actual completion/entry times. After loading, the same scene/window/watchdog are constructed. Each callback performs at most the original one sample body; no callback Task, manual RunLoop pump, finishLaunching, compensation/replay tick, layout/display or hero-clock operation is added. Existing arm/capture fields and policy string remain; its adjacent samples now mean adjacent observer callbacks, not a display synchronization fence.

Original single Boolean replacement, actual manager/weak identities, native gates, endpoint five buffers,3PNG/512samples, initial1.5s readiness,7.2s callback-entry deadline,7.9s independent window watchdog and15s outer wrapper requirement remain. Global watchdog retains its original minimal-report/_exit boundary and captures only an explicit URL value. Ordinary terminal result first invalidates/nils the sampler, then calls stop once and posts one applicationDefined event to this process's own app queue. No event is posted during collection. [Apple stop](https://developer.apple.com/documentation/appkit/nsapplication/stop%28_%3A%29?language=objc), [Apple postEvent](https://developer.apple.com/documentation/appkit/nsapplication/postevent%28_%3Aatstart%3A%29?language=objc). No terminate/exit bypass is used for ordinary completion: app.run returns, then the original owning defer closes/writes. @main's existing exit decision occurs after that defer.

`report.execution_model.kind=nsapplication_run_delegate_default_timer`. Fields: launch_completed_count/uptime; loop_entry_count/uptime; loop_return_count/uptime; sampler_mode, sampler_observed_modes, sampler_interval_seconds, sampler_callback_count, sampler_reentrant_callbacks, sampler_max_depth, sampler_callbacks_after_terminal, sampler_invalidated_before_stop; terminal_count/uptime; stop_calls, wake_count, wake_after_terminal, wake_type=applicationDefined, wake_posted_to_own_app_queue; preload_started_uptime/preload_completed_uptime. The invalidated-before-stop Boolean is a **source-path flag after invalidate+nil**, not an independent Timer.isValid observation. Successful flow requires one launch/run-entry/return/stop/wake, no reentrance or post-terminal sampler callback. A failed/missing wake remains incomplete; no fallback pump/retry is added.

Original scalar sampling/capture JSON, partial armed/attempt state, input/output arguments and pixel_acceptance=not performed are preserved. Terminal prevents later sampling; capture checks also abort if an unexpected nested terminal occurred. Non-normal AppKit return preserves failure status and records execution_contract_error. Before/settled visibility and asynchronous mid pixels still require root's offline review; this execution model is not a proven cause/fix or zero-observer-effect claim.
