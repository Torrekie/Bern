# Frame closed collector and fixed observer-effect gate

Root-owned candidate, frozen before CI publication. No local app/UI or layout execution occurred.

FrameClosed.swift derives from the verified f9 AOT external collector (77e4bb6849ea226cb4bcc4bacac7b08197e8f5a18f4aa991752d81cea44c4db8), recorded by derive-collector.py and FrameClosed.patch. This reuses collector code, not f9 product or screenshot acceptance. Product provenance is fixed e48. Its seven-argument interface remains APP CLI OUTPUT EXPECTED_OS LABEL SOURCE_SHA. Local13 still requires the existing explicit BERN_FRAME_LOCAL_EVENTS=own-pid-active13 outside CI; no CI impersonation, TCC or personal-device changes.

Only the original closed capture runs. Ready→play/pause/seek→Paused0, >3.2s awake, public own-PID/window identity, original raw CGWindowID array, original ICC-preserving screenshot and ≥4 equal comparisons remain. Caption=true and Light window context are verified, while exact generated Frame is dark. No native AXPress is invoked. Additional capture timestamps refer to the actual stable CG image sample. They are not a presentation synchronization fence.

Observer mode requires a precreated empty absolute nonsymlink OUTPUT/ledger, supplied through BERN_FRAME_ROW_LEDGER_OUTPUT_DIR. Before the original Frame selection, the collector writes frame-row-ledger.arm.json (schema bern_frame_row_arm_v1, own Gallery PID, stage frame-closed-light, unique token and arm uptime). At completion it requires a regular ≤65536B matching ledger, nonempty ≤64 complete placements, no truncation, matching PID/token/stage, main-thread placements after arm and the latest completed placement before the actual stable image call. end_state=not_observed remains explicit; the collector independently observes child cleanup. A missing/later placement is a conservative evidence failure, not a layout or pixel cause. Both completion and cleanup reject BERN_FRAME_ROW_LEDGER_IO_ERROR in the bounded application log, including failed writes that left an older valid prefix.

Cleanup first requests the immediate original live application while own child remains frontmost, then stops only its own Process child. A changed foreground is preserved. Failed restore leaves the live child/IPC for explicit guarded cleanup and fails the report and exit. An unstopped child also fails; IPC is removed only when the child stopped. For local13 execution root still owns the existing independent kernel-identity FocusGuard wrapper. This collector does not claim a new general PID/kernel guard.

PixelGate.swift interface is CONTROL_REPORT OBSERVER_REPORT FRESH_PAIR_JSON. Both reports must be successful closed-only same-OS exact-e48 captures with stopped children, stable4, same media and expected context; control trace is off and observer trace on. Actual PNG hashes and decoded ICC bind back to the capture reports. The gate compares original decoded active byte pixels, requires equal raster descriptors/ICC, does no resampling or color conversion, and excludes row padding. The fixed Frame detail ROI [211,52,920,668] points comes from the existing historical Frame boundary and was selected before the new pair. Whole-window differences are separately reported and are not silently accepted as whole-window equality. Pass means no observer effect in this Frame region; it does not establish cross-OS equivalence or the entire application's visuals. Raw provider format is reported, not assumed to be RGBA channel order.

The three targeted typechecks used local Xcode15.2/Swift5.9.2, SDK14.2, language5, arm64/min13; logs/exit codes and immutable source hashes are in typechecks.json. RowTypecheck.swift contains the exact modified BernRow block and helper, plus imports and the existing spacer key; this is not a full product build or native layout run. All passed. The fresh task module cache was retired only after all compiler processes finished and lsof found no open files: 49,800,734 logical bytes, not measured APFS reclamation.

Actual macOS14 control/observer runs, pixel gates, macOS13 comparison, row-ledger interpretation and any product fix remain unperformed at this freeze.
