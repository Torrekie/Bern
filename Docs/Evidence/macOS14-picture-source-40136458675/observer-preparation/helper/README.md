# Private Picture Scene observer helper

`PictureSceneObserver.swift` is a 187-line source-only helper. Append `.bernPictureMeasure("label")` at the agreed generated-source sites and compile this file in the same module. The internal extension and store are `@MainActor`; the syntax uses no Swift 6-only isolation escape. No compile, typecheck, UI, CI, or pixel test was performed here. Parent will separately check SDK14.2/Swift5.9 syntax and the full SDK26.2/Swift6 application.

The source has a transparent `GeometryReader` background and an `NSViewRepresentable` whose native view does not draw or receive hits. Only the background is accessibility-hidden. It adds no frame, padding, font, gesture, Scene, row-height override, color, theme override, timer, scheduled task, explicit layout flush, or state published back to SwiftUI. The existing full reference collector and its Layout pause of 0.8 seconds remain outside this helper and unchanged.

## Recorded values

The ten environment names match the old `EnvironmentProbe`: `dynamic_type_size`, `size_category`, `default_min_list_row_height`, `control_size`, `color_scheme`, `contrast`, `layout_direction`, `display_scale`, `locale`, `font`. These are **the transparent probe branch's inherited environment at the modifier site**. They are not a resolved `Text` font, glyph metrics, or a proposed size. In particular, an earlier content-local `.font(.caption)` need not be visible to a later background branch; `inherited nil` cannot establish the actual text font.

Each valid observation includes the GeometryProxy resolved size/global frame and the attached native probe's public bounds, frame, identity, class, flipped flag, and coordinate conversions. It also reads the owning window's public frame/contentLayoutRect/scale/visibility/key/main/level values; content view; nearest `enclosingScrollView`'s scroll, clip and optional document views; and at most six superviews. Those records contain only strings, booleans, and numbers, without retaining AppKit objects. Observed class names are getter output, not private API calls.

Node `frame_in_superview` uses that native parent's coordinate system; `bounds_local` and `probe_bounds_in_node` use the node's coordinates. `bounds_in_window_base` is the public conversion with destination `nil`; `bounds_in_screen_bottom_left` then uses `NSWindow.convertToScreen`. `content_layout_rect` copies the public window property. `swiftui_global_frame` belongs to SwiftUI's `.global` space and must not be silently equated with AppKit window or screen coordinates. A six-node ancestor chain may be truncated; a null nearest scroll view is an unresolved native association, not proof that the semantic Form has no scrolling. Probe bounds and GeometryProxy size may temporarily differ; the exact equality flag records that distinction rather than filtering it away.

The agreed 21 labels are `form-root`; `images-grid`, `hdr-grid`; `images-{contain,cover,fill,mark}-{column,image,caption}`; and `hdr-{gainmap,pq}-{column,image,caption}`. These label view attachment sites. A grid/column/image/caption probe is not an identified native card; this helper has no Section anchor or native-card bounding-box claim. The full PNG's 125-point first-card and 147-point HDR-card control gates remain required.

## Output and limits

Set `BERN_PICTURE_OBSERVER_OUTPUT_DIR` to an existing owned output directory. The only requested destination is `picture-observer-<own PID>.json` in that directory. Missing directory/environment or a pre-existing destination disables recording. The first write uses `.withoutOverwriting`; subsequent writes atomically replace this process's history file. No alternate output or directory is created. Parent must use a fresh output directory, bind the filename PID to the actual Showcase process, and reject absent/invalid JSON.

`updateNSView`, native move/layout/frame callbacks may observe a valid attached state. Window nil, nonfinite/invalid sizes or coordinate conversions are skipped. There is no dismantle/unmount write. Per-label consecutive identical environment/geometry observations are deduplicated before the callback name, sequence and uptime are added; returning A→B→A remains three events. Accepted history is append-only, at most 256 events, with each complete serialized file at most 512 KiB. A capacity, serialization, or I/O failure stops recording and keeps the last successful file. It does not manufacture a terminal record. The envelope permanently says `end_state: not_observed`; the last entry is neither an independently stable result nor proof the file did not reach a limit. Consumers must inspect label coverage, sequence, geometry and external capture timing.

The timestamp is append-time uptime after the public reads, not a rendering completion, callback-entry time, or PNG timestamp. Synchronous JSON/I/O and the added native background view can disturb scheduling or layout. No claim of observer noninterference is made by source review. The next control→observed full-window comparison, using identical source/assets/route/window/language/normal settings/scale, must establish the required image/geometry result. This helper does not weaken those gates or add color/pixel analysis.
